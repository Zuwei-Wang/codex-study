# 学习偏好

[English](LEARNING_PREFERENCES.md)

首次设置会提供四个可选问题：平时的学习节奏、倾向自学还是听课、合适的单次学习时长，以及希望得到多少督促。可以只答一部分、全部跳过，也可以以后修改或清除。没有回答不等于明确跳过；已有答案或已记录跳过时，不会每次启动都重新询问。

这些是用户自述、可以变化的偏好，不是人格标签、能力评分或经过验证的教学诊断。不会根据迟交、成绩、缺失进度或课件内容猜测习惯。用户当前的明确要求优先。

| 用户选择           | 如何调整建议                                       |
| ------------------ | -------------------------------------------------- |
| 按部就班           | 建议规律的学习块                                   |
| 常在截止前集中完成 | 建议一个容易开始的小行动，以及可选的提前个人里程碑 |
| 看任务而定         | 建议可调整的学习块                                 |
| 以自学为主         | 有范围的阅读、例题、练习和回顾                     |
| 以听课为主         | 课前问题与课后复习，不推断已经出勤                 |
| 两者结合           | 组合预习、学习和练习                               |
| 单次学习时长       | 用户明确选择 10–180 分钟；未回答则未知             |
| 希望怎样帮助       | 小步骤/检查点、轻量总览，或只在主动询问时帮助      |

setup、课前准备、课件学习、自测和复盘 Skills 会参考这些选择。已实现的是建议流程，教学效果仍需真人试用评价。偏好不会改动官方截止日期、学习进度，也不会自动开启邮件或定时任务。建议检查点不代表提醒已经运行。

## 保存、修改与清除

偏好只保存在本地学习工作区的 SQLite 中，会出现在私有快照里，不进入发送给提醒服务的最小数据投影。Codex 读取快照时，偏好会进入当前对话；不要把真实偏好或工作区导出发到公开 Issue。

- `study_preferences_get` 读取当前偏好和对应的规划建议；记录为 null 表示尚无答案。
- `study_preferences_save` 使用当前 `expectedRevision` 保存用户实际提供的选项，状态为 `provided`，省略未回答项。明确跳过时保存 `{ "status": "skipped" }`；要求清除时保存 `preferences: null`，以后可重新问卷。
- 修改前读取当前版本；相同重试不会重复写入，不同的旧版本修改会被拒绝，避免覆盖另一处更新。
- 只保留当前记录，不建立偏好历史或个人传记。

CLI 也可使用：

```sh
npm run study -- preferences --workspace /absolute/learning-workspace
npm run study -- preferences-save --workspace /absolute/learning-workspace --input /absolute/private/preferences.json
```

[输入示例](../examples/demo-workspace/preferences.json)使用虚构偏好，不应当作默认答案套给所有用户；示例的 null 版本仅适用于新记录。

## 已有工作区

0.5.0-dev.1 使用数据库 schema 4。旧 schema 1–3 需要先关闭访问工作区的工具、保留完整备份，再明确执行：

```sh
npm run study -- upgrade --workspace /absolute/learning-workspace
```

迁移通过事务新增偏好存储及旧版本缺少的表，保留配置、资料、引用、任务证据、进度、课表与调度设置。旧用户的偏好起初仍为未知。安装或更新插件本身不会授权或执行此迁移；旧客户端不能读取 schema 4，目前没有降级功能。
